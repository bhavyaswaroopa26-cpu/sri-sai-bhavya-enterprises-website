# Sri Sai Bhavya Enterprises

A responsive, premium tea and coffee website for Sri Sai Bhavya Enterprises in Rajamahendravaram, Andhra Pradesh.

## Run locally

Open `index.html` in a browser. The site uses plain HTML, CSS and JavaScript with no build step or package installation.

## Features

- Responsive product, wholesale, gallery and contact sections
- WhatsApp product enquiries and contact form handoff
- Google Maps directions and embedded location map
- Visitor feedback saved locally in the visitor's browser
